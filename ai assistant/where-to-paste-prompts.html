🤖 Claude.ai — Step by Step
1
Go to claude.ai and sign in
Open your browser. Go to claude.ai. Sign in or create a free account. Upgrade to Pro ($20/month) for best results — gives you access to Claude Sonnet 4.6 which is what you want for coding.

You land on this screen. You will see a chat interface — exactly like WhatsApp but for AI. This is where everything happens.
2
Start a New Chat for each feature
On the left sidebar, click "New Chat" button (pencil icon or + button). Each feature you build = a new chat. This keeps your work organized and Claude focused.

What do you want to build?
👆
Click "New Chat" (top left, pencil/plus icon). Name your chats like "LexAI — Contract Analyzer" so you can find them later. Keep one chat per feature.
3
THIS is where you paste your prompt ↓
At the bottom of the screen there is a large text input box. This is called the "message input." Click it, paste your entire prompt, then press Enter or click the Send button (arrow icon ↑).
claude.ai
Hello! Ready to help you build LexAI. What would you like to create?
I am building a SaaS product called LexAI — an AI legal co-pilot for small businesses. Please set up a complete Next.js 14 project with TypeScript, Tailwind CSS, Supabase...
↑
⭐
THIS is the box. Click anywhere in the large text area at the bottom. Paste your full prompt (Ctrl+V on Windows, Cmd+V on Mac). Press Enter or click the orange/gold arrow button. That's it.
💡
Pro Tip: For long prompts (like the project setup prompt), use Shift+Enter to add new lines inside the box without sending. When you're ready, press plain Enter or click Send.
4
Claude responds with code — here's what to do with it
Claude will write code for you. The code appears in gray code blocks inside the chat. Each block has a "Copy code" button in the top-right corner of that block.
claude.ai
Here is your Next.js project setup for LexAI. Create this file structure:
package.json
// package.json { "name": "lexai", "dependencies": { "next": "14.0.0", "@supabase/supabase-js": "^2.38.0", "stripe": "^14.0.0", "@anthropic-ai/sdk": "^0.24.0" } }
👆
See the "Copy code" button in the top-right of each code block? Click it. The code is now in your clipboard. Go to VS Code, create the correct file, and paste it (Ctrl+V).
📁
VS Code is free. Download at code.visualstudio.com. Create a new folder called "lexai". Open it in VS Code. When Claude says "create this file at /app/dashboard/page.tsx" — create that file in VS Code and paste Claude's code into it.
5
When you get an error — paste it right back into Claude
You will get errors. This is 100% normal. Don't panic. Copy the error message, go back to your Claude chat, and paste this:
I got this error when running the code: [paste your exact error message here] My current code is: [paste the file where the error is] Please fix it and tell me what was wrong.
🔄
The loop: Prompt → Code → Paste into VS Code → Error → Paste error into Claude → Fixed code → Paste again. This is the entire building process. It repeats until the feature works.

💜 Lovable — Step by Step
👋
Use Lovable if you cannot code at all. Lovable is like talking to a builder — you describe your app in plain English and it builds the entire thing, deploys it live, sets up the database, and handles authentication. No VS Code needed. No terminal. Just type and click.
1
Go to lovable.dev and create account
Open your browser. Go to lovable.dev. Sign up with Google. Choose the Starter plan ($20/month) — gives you 100 credits/month which is enough to build LexAI MVP.

Click "New Project" — give it a name

Inside your project, you see a chat box at the bottom (just like Claude). This is Lovable's build interface. Type or paste your prompt here. Lovable builds the entire app and shows a live preview on the right.

Build a SaaS app called LexAI — an AI legal co-pilot for small businesses. I need: 1) User signup/login, 2) A dashboard where users can upload contracts, 3) Show the contract text after upload, 4) A chat interface where they can ask legal questions...

THIS chat box at the bottom is where you paste your prompt. Click inside it. Paste your prompt (Ctrl+V or Cmd+V). Press Enter or click the orange Send button. Lovable builds the entire page and shows a live preview instantly.
4
Connect Supabase (database) — one click
When Lovable builds something that needs a database, a banner appears: "Connect to Supabase". Click it. Sign in to Supabase (free account). Lovable automatically sets up your database, tables, and authentication. You don't write a single line of database code.
🗄️
When you see the "Connect Supabase" banner — click it. Create a free Supabase account at supabase.com. Authorize the connection. Done. Your database is live.
5
Iterate: describe what to change in plain English
After Lovable builds something, you can keep typing in the same chat box to change it. Just describe what you want differently — no code needed.
The button color should be dark blue, not orange. Add a navigation menu at the top with: Dashboard, Contracts, Chat, Settings. Make the contract upload area bigger and add a drag-and-drop zone. Add a "Risk Score" badge next to each contract that shows High/Medium/Low.
🎨
Lovable's power: You just describe changes in plain English. "Make the header darker." "Move the button to the right." "Add a loading spinner." Lovable updates the code and shows you the new preview immediately.
6
Deploy your app live — one click
When you're ready to share with users, click the "Publish" button (top right). Lovable gives you a live URL like lexai.lovable.app that anyone can access. You can also connect your custom domain (lexai.com).
🚀
Click "Publish" → your app is live on the internet in 30 seconds. Share the URL with beta users. This is your MVP. From idea to live app in one afternoon.
